# Brick by Brick Tab

[English version](README.md)

Автор: BRICK. Telegram: https://t.me/brickstu

Клиентский Fabric-мод для Minecraft 26.2. Смотрит, какие блоки ты ставишь, угадывает следующий и рисует его призраком.

Обученная модель не обязательна. Без весов мод всё равно предлагает варианты по простым правилам вроде "продолжи линию". Природный ландшафт в обучение и во вход модели не идёт.

## Установка

1. Minecraft 26.2, [Fabric Loader](https://fabricmc.net/) 0.19.3+, Fabric API.
2. Положи `brickbybricktab-0.1.0.jar` в `mods/`.

Свои веса можно положить вручную, либо мод сам заберёт последнюю опубликованную пару
с каталога на том же хосте, что и `telemetryEndpoint` (по умолчанию `https://bbb.ruscreat.dev`):

```
<game>/config/brickbybricktab/model/model.bbbt
<game>/config/brickbybricktab/model/palette.json
```

В настройках видна версия из каталога, если файлы пришли с сервера.
Кнопка "Перезагрузить модель" проверяет, нет ли более новой записи. `autoUpdateModel`
(включено по умолчанию) ещё проверяет при запуске и раз в несколько часов.
В `config.json` поставь `autoUpdateModel` в false, если хочешь держать локальный файл.

Потом нажми "Перезагрузить модель" в настройках или перезапусти игру.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| B | Вкл/выкл подсказки |
| V | Следующая подсказка |

Настройки, подтверждение, описание постройки и клавиши контекстной области по умолчанию не назначены. Поставь их в управлении, если нужны. Подтверждение может поставить блок, поэтому оно специально без клавиши.

## В игре

- Призрак в пустой клетке под прицелом (зелёный, если блок есть в инвентаре, красный если нет).
- Список подсказок на HUD.
- Быстрая установка из инвентаря: ПКМ по призраку, ванильный свап на хотбар, потом обычная постановка. Ничего не спавнится.
- Обучение на этом компьютере по твоим установкам. Для этого ничего никуда не уходит.
- Два отдельных вопроса согласия, если когда-нибудь захочешь делиться данными: данные о постройках и описания построек.

## Модель

Небольшой трансформер, который предсказывает следующий поставленный игроком блок.

| | |
| --- | --- |
| Параметры | около 3.2 млн |
| Размер | dim 192, 6 голов, FFN 512 |
| Энкодер | 4 слоя, self-attention |
| Декодер | 2 слоя, только cross-attention (один query-токен) |
| Контекст | последние 64 поставленных блока |
| Голова позиции | относительная сетка 16x16x16 (4096 клеток, смещения от -8 до +7) плюс stop |
| Словарь блоков | 816 (814 строительных блоков + none/unk) |
| Ориентация | 24 |

Два шага: сначала куда идёт следующий блок, потом какой блок и поворот в этой клетке.

Во вход идут только блоки, которые ставил игрок. Природный ландшафт туда не попадает.

## На чём училась

- Дома [3D-Craft](https://github.com/facebookresearch/craftassist) (Facebook AI / VoxelCNN, ICCV 2019): около 2500 построек в Creative с реальным порядком кликов.
- [Minecraft Fable](https://huggingface.co/datasets/TheAIdude303/Minecraft-Fable-Schem-final): около 28 тысяч схематик игроков. Порядок установки восстановлен по соседству, это не записанные клики.
- Палитра только строительных блоков (дерево, камень, стекло и так далее). Руды, ландшафт, растения и жидкости не входят.

В рантайме крутится Java из этого репозитория. Веса это файл `.bbbt` плюс `palette.json`.

## Как обучить свою модель

Источник правды это Java в `src/main/java/dev/bbbt`. Тренер должен попасть в эту спецификацию,
иначе мод файл не примет. Код обучения в этот репозиторий не входит: ниже хватает, чтобы
написать свой тренер или скормить дамп уже существующему.

### Задача

По последним 64 блокам, которые поставил игрок, предсказать следующий в два шага:

1. Куда он идёт: клетка на сетке 16x16x16 относительных смещений (от -8 до +7) плюс бит stop.
2. Какой блок и какая из 24 ориентаций, если клетка уже выбрана.

Природный ландшафт во вход не класть. Только то, что ставил игрок.

### Данные

Публичные наборы, которые для этого уже подходят:

- Дома [3D-Craft](https://github.com/facebookresearch/craftassist): реальный порядок кликов.
- [Minecraft Fable](https://huggingface.co/datasets/TheAIdude303/Minecraft-Fable-Schem-final): схематики игроков. Порядок установки восстанавливают ростом от семени по соседству, это не записанные клики.

Опциональная телеметрия мода это JSONL, одна последовательность на строку, уже в относительных координатах, без id игроков:

```
{"session": 3, "steps": [
  {"dx": 0, "dy": 0, "dz": 0, "block": "minecraft:stone", "orient": 0},
  {"dx": 1, "dy": 0, "dz": 0, "block": "minecraft:oak_planks", "orient": 0}
]}
```

Если крутишь сборщик, выгрузи шарды постановок (верхний уровень `*.jsonl`, не `_index/`)
и укажи тренеру эту папку.

### Архитектура, в которую надо попасть

Эти числа лучше не трогать, пока не меняешь ещё и `dev.bbbt.model.ModelSpec` с `WeightStore`:

| | |
| --- | --- |
| dim | 192 |
| голов | 6 |
| FFN | 512 |
| энкодер | 4 слоя self-attention |
| декодер | 2 слоя, только cross-attention, один query-токен |
| контекст | 64 |
| сетка | 16^3 = 4096 клеток |
| словарь | 816 с палитрой по умолчанию (814 блоков + none + unk) |
| ориентации | 24 |
| параметры | около 3.2 млн |

GELU это tanh-приближение. LayerNorm считает дисперсию по всей выборке, `ln_eps = 1e-5`.
У памяти энкодера нет финального LayerNorm. Двумерные веса остаются в раскладке PyTorch
`[out, in]`; Java считает `y = x @ W^T`.

Рабочий рецепт: AdamW, cosine с warmup, сглаживание меток около 0.05,
loss = CE(позиция) + CE(блок) + CE(ориентация) + BCE(stop). Аугментация: вращения и
отражения постройки в группе D4, чтобы один и тот же дом не смотрел всегда в одну сторону.

### Файлы, которые читает мод

`palette.json`:

```
{"format": 1, "blocks": ["minecraft:stone", "..."], "aliases": {}}
```

Токен 0 это none, токен 1 это unk, `blocks[i]` это токен `i + 2`. Размер словаря в заголовке
весов должен совпасть с `len(blocks) + 2`.

`model.bbbt`, заголовок big-endian, полезная нагрузка little-endian:

```
байты 0..3   ASCII BBBT
байты 4..7   int32 BE  версия контейнера = 1
байты 8..11  int32 BE  длина заголовка
дальше       UTF-8 JSON {arch, tensors:[{name, shape, dtype, offset}]}
дальше       тензоры в порядке объявленных offset
```

В `arch` нужны `dim`, `heads`, `ff_dim`, `enc_layers`, `dec_layers`, `vocab`,
`orient_count`, `grid_volume`, `ln_eps`. Веса обычно fp16; bias и параметры LayerNorm
оставляют fp32.

Скопируй оба файла в `config/brickbybricktab/model/` или опубликуй их в каталоге,
с которым мод уже умеет разговаривать:

- `GET /v1/model/latest` отдаёт `{version, weightsSha256, paletteSha256, weightsBytes, paletteBytes}`
- `GET /v1/model/{version}/weights` и `.../palette` это два файла

Строка `version` твоя (`v4`, `2026-08-18` и так далее). После успешной загрузки мод
показывает её в настройках.

## Что осталось только в файле

В меню только то, что реально крутят в игре. Остальное по-прежнему в `config/brickbybricktab/config.json`:

- `refreshDelayTicks`, `previewDepth`, `bulkChangeThreshold`
- `debugOverlay`
- LoRA: `loraStrength`, `loraTrainEveryPlacements`, `loraScope`, rank, learning rate
- `captionCollectLocally`
- `telemetryEndpoint`, `captionEndpoint`, `modelOverridePath`
- `autoUpdateModel`, `modelEndpoint` (пустой `modelEndpoint` берёт `telemetryEndpoint`)

## Сборка

Нужен JDK 25. Из корня репозитория:

```
./gradlew build
```

На Windows: `.\gradlew.bat build`. Готовый jar в `build/libs/`.
